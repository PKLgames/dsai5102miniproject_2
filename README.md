## What the study asks

Development monitoring is indicator-rich and data-poor at once. Using 28 World Development
Indicators for 198 economies over 2005–2022, compressed to one profile per country:

1. **Does development have one dominant, stable axis?** PC1 explains 47.9% of the variance
   (95% bootstrap CI 44.4–51.6%). The country ranking it induces survives deleting any single
   indicator (ρ ≥ 0.9986), resampling countries (ρ ≥ 0.9974) and changing the time window
   (ρ ≥ 0.9826).
2. **How few indicators reproduce it?** Twelve, chosen label-blind by sparse PCA, reproduce the
   full ranking at ρ = 0.9935 and predict income groups at macro-F1 0.821 against 0.834 for all 28.
   Three (GDP per capita, mobile subscriptions, GDP growth) reach 0.803 balanced accuracy once
   selection is moved inside the cross-validation fold — the naive protocol's 0.849 is inflated
   by selection bias.
3. **How many kinds of country are there, and who is moving?** Three stable archetypes
   (advanced, mature middle, emerging frontier; bootstrap ARI 0.953). Over two non-overlapping
   windows the ranking persists at ρ = 0.986 while China gains 32 rank places and Venezuela loses 34.

The practical claim: three near-complete series will *screen* a country, twelve will *place* it,
and the remaining sixteen buy diagnosis rather than ordering.

## Reproducing

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt      # analysis + document toolchain
                                     # the PDF build also needs a `pandoc` binary on PATH

python src/01_preprocess.py      # 4 s   panel construction, coverage report
python src/02_index.py           # 2 s   index + stability (E1, Table 2, Figure 2)
python src/03_selection.py       # 630 s the two shortlists (E2, Table 3, Figure 3)
python src/03b_fig_selection.py  # 3 s   selection figure + fidelity table
python src/04_classify.py        # 95 s  classification (E3, Table 4, Figure 4)
python src/05_cluster.py         # 34 s  archetypes (E4, Tables 5-6, Figure 5)
python src/06_dynamics.py        # 6 s   dynamics (E5, Table 7, Figure 6)
python src/07_robustness.py      # 48 s  robustness (E6, Table 8)
python src/10_slide_figs.py      # 3 s   the two simplified slide figures (S1, S2)

python report/build_report_pdf.py report/DSAI5102_Group16_Report.md   # -> PDF
python slides/build_slides.py                                        # -> PPTX
python slides/preview_slides.py                                      # -> slides/preview/
```

The two toolchains (numeric stack, document stack) were originally installed in
separate environments and run fine that way; a single environment also works. All
scripts resolve paths relative to the repository root, so they can be run from
anywhere.

Everything is single-threaded and seeded (`random_state` 0 / 42 / 7 / 11, bootstrap B = 200);
the full analysis runs in under 15 minutes on a laptop CPU with no GPU.

## Layout

```
data/raw/         frozen WDI response, country metadata, PROVENANCE.md (retrieval date + SHA-256)
data/processed/   panel, country-level matrix, data dictionary
src/              common.py (indicator schema, paths, table writer), country.py (aggregation,
                  index, window alignment), sparse_solver.py, and the eight numbered stages
results/metrics/  one JSON per experiment — the numbers quoted in the report
results/tables/   every table as CSV plus a LaTeX body
results/figures/  F1–F6 (report, PDF + PNG) and S1–S2 (slides)
report/           Markdown source, CSS, PDF builder
slides/           deck builder, deck, per-slide previews
```

## Notes

- Data: World Bank World Development Indicators via `api.worldbank.org/v2`, CC BY 4.0. The frozen
  copy in `data/raw/` lets the pipeline be rerun without network access.
- The PDF is typeset for print (A4, Times, 9–11 pt); the deck is 16:9 and uses Liberation/Arial.
- `slides/preview/*.png` are raster previews of the deck produced by
  [`slides/preview_slides.py`](slides/preview_slides.py) for review without PowerPoint; they are
  not part of the printed deliverable.

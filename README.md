## What the study asks

Development monitoring is indicator-rich and data-poor at once: frameworks list hundreds of
indicators, while the economies that most need targeting report the fewest. The paper asks how far
the indicator set can be reduced **for a specified task**, using 28 World Development Indicators for
198 economies over 2005–2022 (one profile per economy).

1. **Is there one dominant, stable ranking direction?** The first component explains 50.1% of the
   standardised variance (95% bootstrap interval 46.6–53.7%). The ranking it induces survives
   deleting any single indicator (ρ ≥ 0.999; minimum 0.9986), resampling economies (ρ ≥ 0.998) and
   changing the time window (ρ = 0.986).
2. **How few indicators reproduce that ranking?** Nine, selected by sparse PCA at the fidelity
   threshold (ρ = 0.992 against the full index). On the reported split the frozen nine-indicator list
   reaches macro-F1 0.856 for income-group classification, the same score as a procedure that
   re-selects 17–18 indicators inside every training fold, and above the 0.844 of the full menu; a
   nested three-indicator screen reaches 0.820. Across ten split seeds the fixed list averages 0.012
   below the reselected procedure, so the equality is a property of the split, not of the list.
3. **Do country profiles add anything beyond the ranking?** A two-group partition is the most stable
   one (silhouette 0.533, bootstrap ARI 0.938 over 2–6 groups), and the cross-window rank correlation
   is 0.986 while individual economies move a lot (China +28, Georgia +25, Qatar +22; Jamaica −24,
   Libya −24, Venezuela −40).

The practical claim is deliberately modest: nine indicators are a **candidate reporting layer** for
broad ordering and income-group screening within this menu, not a policy-ready replacement for the
full indicator set.

## Reproducing

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
```

```bash
# 1. data: from the World Bank WDI archive (WDICSV.csv + WDICountry.csv inside the zip)
python scripts/extract_official.py /path/to/WDI_CSV.zip   # -> results/official_panel.csv

# 2. analysis -> results/analysis.json (about 100 s, single-threaded, no GPU)
python scripts/analyse.py

# 3. figures and tables
python scripts/make_figures.py     # structure, selection, groups
python scripts/add_figures.py      # missingness, workflow, confusion, rank_changes
python scripts/export_tables.py

# 4. optional: ten split seeds (about 50 s)
python scripts/repeat_splits.py

# 5. documents
python scripts/build_report.py       # needs pandoc + LibreOffice -> Word-styled PDF
python scripts/build_report_html.py  # pandoc + WeasyPrint only -> same text, different type
```

Both builders read `report/DSAI5102_Group16_Report.md` and write
`report/DSAI5102_Group16_Report.pdf`; the second exists because the WeasyPrint path needs no
LibreOffice and can run on any machine with the Python dependencies. The two display equations are
typeset as Unicode text in the WeasyPrint build, since it has no MathML support.

The deck is edited in PowerPoint; it is not generated by a script.

## Notes

- **Data.** World Bank *World Development Indicators*, CC BY 4.0, accessed through the official
  World Bank API. `results/official_panel.csv` is the frozen extract the analysis runs on: 217
  economies × 18 years (2005–2022) = 3,906 economy-years before the coverage filter; its SHA-256
  (`abbe2367…`) is stored as `input_zip_sha256` in `results/analysis.json`, and per-artefact
  checksums are in `results/file_checksums.json`. `data/PROVENANCE.md` records the earlier pull.
- **Everything is seeded** (`random_state` 0 for the sparse path, 7 for the main split, 42 for
  repeats). The classification comparison uses a single 5-fold stratified split, which is why the
  split-seed check in `results/repeat_splits.csv` is reported alongside it.
- **Archive.** `archive/` holds the earlier drafts (reports v1–v3, decks v1–v2, the WeasyPrint
  builder, the `F*`/`S*` figures and the `E*` metric files). Nothing outside `archive/` is legacy:
  `report/`, `slides/`, `scripts/`, `results/` and `data/` are the current submission.
